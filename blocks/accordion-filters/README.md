# accordion-filters

Custom **accordion** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per filter group: title | type (checkbox | prefixed-text | date-range) | options list (ul; checkbox labels, prefix values, or Start/End labels) | optional help text.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
