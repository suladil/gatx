# cards-contact

Custom **cards** block. Purpose: Service team contact list, one contact per row stacked vertically.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: first cell is the portrait photo (with alt text = person name); second cell is rich text with the name as a heading (h3), the role as a paragraph, and a paragraph with Phone: ... line break Fax: ....

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
