# table-report

Custom **table** block. 

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: first row is the header (column names); each following row is one report record with the same number of cells (13 for the service events report). Cells may be empty, contain :icon: names (:expand:, :alert:, :wrench:) or links..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
